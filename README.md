## 📖 How to Use

1. **Navigate to relevant folder** - Choose a topic you want to learn
2. **Read the implementation files** - Study the code and comments
3. **Understand the logic** - Read through the algorithm explanations
4. **Practice problems** - Try solving the problems in each folder
5. **Test & Verify** - Run the code and test with different inputs

## 🔧 Compilation & Execution

### Compile a Java file:
```bash
javac FileName.java
```

### Run a Java program:
```bash
java FileName
```

### Compile all Java files:
```bash
javac *.java
```

## 💡 Quick Comparison Table

| Data Structure | Time Complexity | Space | Best For |
|---|---|---|---|
| Array | O(n) lookup | O(n) | Random access |
| LinkedList | O(n) lookup | O(n) | Insertion/Deletion |
| Stack | O(1) push/pop | O(n) | LIFO operations |
| Queue | O(1) enqueue/dequeue | O(n) | FIFO operations |
| BST | O(log n) avg | O(n) | Sorted data |
| Hash Table | O(1) avg | O(n) | Fast lookup |
| Heap | O(log n) insert/delete | O(n) | Priority queue |
| Graph | Varies by algorithm | O(V+E) | Network problems |
